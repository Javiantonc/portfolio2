# Portfolio 2 · Javier Antón

Sitio web personal y portafolio interactivo de Javier Antón, desarrollador web en Madrid.

## 🚀 Tecnologías

- **HTML5**
- **CSS3** (Variables CSS, Animaciones 3D, Stacking horizontal sticky)
- **JavaScript** (Interactividad y efectos de scroll/tilt)

## 💻 Visualización

Para ver el proyecto, simplemente abre `index.html` en tu navegador o despliégalo en plataformas como Vercel o GitHub Pages.
